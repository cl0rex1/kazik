# 🎰 CYBER VEGAS 777 - 3-Барабанный Глазораздирающий Онлайн Слот

Неоновый слот-автомат нового поколения (классический формат **3 барабана x 3 ряда, 5 линий выплат**), созданный на чистом **HTML5, CSS3 и Vanilla JavaScript**. Готов к мгновенному запуску на **GitHub Pages** без сборщиков, внешних зависимостей и сторонних аудиофайлов.

## 🔥 Особенности и Эффекты

- **Классический формат 3x3**:
  - 3 барабана с большими сочными символами (777, Корона, Алмаз, Колокол, Клевер, Вишня, Лимон, Wild ⭐, Scatter ⚡).
  - 5 выигрышных линий (3 горизонтали и 2 диагонали).
- **Кнопка «Поделиться» (📸 Скриншот)**:
  - Генератор стильной графической карточки заноса прямо в браузере с помощью HTML5 Canvas.
  - Нативная отправка через **Web Share API** (в Telegram, WhatsApp, AirDrop и соцсети на смартфонах и ПК).
  - Кнопки быстрого скачивания PNG-картинки и копирования в буфер обмена.
  - Возможность поделиться прямо из всплывающего окна Мега-победы!
- **Глазораздирающие эффекты побед**:
  - **4 уровня празднования**: *Хороший выигрыш*, *Большой куш!*, *Мега выигрыш!* и *ДЖЕКПОТ БОГОВ!*.
  - **Физический Canvas-движок 2D-частиц**: реалистичный фонтан золотых монет с 3D-вращением, гравитацией и отскоком от пола, лавина конфетти и искрящиеся фейерверки.
  - **Тряска экрана (Screen Shake)** и стробоскопические неоновые вспышки (Strobe FX / Chromatic Aberration).
  - **Динамическая подсветка линий**: лазерные неоновые линии выигрыша, соединяющие победные символы по 5 направлениям.
- **100% процедурный звук (Web Audio API)**:
  - Механические щелчки вращения, сочный стук остановки барабанов, нарастающий саспенс при ожидании 3-го Scatter, победные аккорды, сирена джекпота и звон монет без внешних `.mp3` / `.wav` файлов.
- **Удобное управление**:
  - Интерактивный **3D-рычаг** справа.
  - Горячая клавиша `ПРОБЕЛ` (пробел автоматически закрывает окно победы и крутит следующий спин).
  - Режимы **ТУРБО** и **АВТОСПИН**.
  - Кнопка **Банкомат** для моментального пополнения баланса фишек при банкротстве.

## 🚀 Как запустить на GitHub Pages

1. Загрузите файлы в ваш репозиторий GitHub (`git push origin main`).
2. Перейдите в настройки репозитория: **Settings** -> **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)`.
4. Нажмите **Save**. Через 30-60 секунд игра станет доступна по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 🎮 Управление

- **КРУТИТЬ** / клавиша `ПРОБЕЛ` — сделать спин.
- **Рычаг справа** — потянуть за рычаг.
- **📸 Скриншот** — сгенерировать карточку текущего результата и отправить друзьям.
- **- / +** — регулировка размера ставки ($5 - $2,500).
- **МАКС СТАВКА** — максимальная ставка в один клик.
- **ТУРБО** — режим молниеносного вращения.
- **АВТО** — непрерывное авто-вращение.
- **Банкомат** — пополнить фишки на $1,000, $5,000 или $20,000.
- **Выплаты** — таблица множителей символов для 3 барабанов.
- **Звук 🔊** — включение / выключение аудио.
