## 🔥 Особенности и Эффекты

- **Глазораздирающие эффекты побед**:
  - **4 уровня празднования**: *Хороший выигрыш*, *Большой куш!*, *Мега выигрыш!* и *ДЖЕКПОТ БОГОВ!*.
  - **Физический Canvas-движок 2D-частиц**: реалистичный фонтан золотых монет с 3D-вращением, гравитацией и отскоком от пола, лавина конфетти и искрящиеся фейерверки.
  - **Тряска экрана (Screen Shake)** и стробоскопические неоновые вспышки (Strobe FX / Chromatic Aberration).
  - **Динамическая подсветка линий**: лазерные неоновые линии выигрыша, соединяющие победные символы по 20 выигрышным направлениям.
- **100% процедурный звук (Web Audio API)**:
  - Механические щелчки вращения, сочный стук остановки каждого барабана, нарастающий саспенс-звук при ожидании 3-го Scatter, победные аккорды, сирена джекпота и звон монет без внешних `.mp3` / `.wav` файлов (гарантия отсутствия ошибок 404 и CORS).
- **Игровые механики**:
  - 5 барабанов x 3 ряда, 20 линий выплат.
  - Символы **WILD ⭐** (заменяет любой символ).
  - Символы **SCATTER ⚡**: 3+ скаттера активируют режим **FREE SPINS** (10 бесплатных спинов с множителем выигрышей x3!).
  - Интерактивный **3D-рычаг** с физической анимацией нажатия.
  - Режим **ТУРБО** (мгновенная быстрая прокрутка) и **АВТОСПИН**.
  - Кнопка **Банкомат** (бесплатное пополнение баланса при банкротстве).
  - Динамически растущие Джекпоты: *Mini*, *Major*, *Grand Jackpot*.

## 🚀 Как запустить на GitHub Pages

1. Загрузите файлы в ваш репозиторий GitHub (`git push origin main`).
2. Перейдите в настройки репозитория: **Settings** -> **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или `master`), папка `/ (root)`.
4. Нажмите **Save**. Через 30-60 секунд игра станет доступна по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 🎮 Управление

- **КРУТИТЬ** / клавиша `ПРОБЕЛ` — сделать спин.
- **Рычаг справа** — кликните по рычагу, чтобы потянуть его и крутануть барабаны.
- **- / +** — регулировка размера ставки ($10 - $2,000).
- **МАКС СТАВКА** — поставить максимальную ставку в один клик.
- **ТУРБО** — включить режим суперскорости.
- **АВТО** — непрерывное авто-вращение.
- **Банкомат** — пополнить фишки на $1,000, $5,000 или $20,000.
- **Выплаты** — посмотреть таблицу выплат и множители символов.
- **Звук 🔊** — включение / выключение аудио.
